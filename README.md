# The Sweets Corner 🍰

A responsive website concept for an Indian sweets shop, featuring a warm espresso-and-gold visual theme, signature sweet cards, a brand story, and a contact section.

## 🌐 Live Demo

**[Visit The Sweets Corner](https://explorecodewithravi.github.io/the-sweets-corner/)**

## ✨ Features

- Responsive layout for desktop, tablet, and mobile screens
- Mobile hamburger navigation with open/close interaction
- Hero section with a prominent call to action
- Signature sweets section featuring Kaju Katli, Gulab Jamun, and Rasmalai
- Clickable sweet cards that navigate to the Contact section
- About/story section and contact call to action
- Hover effects, subtle animations, and smooth in-page navigation
- Custom images and Google Fonts

## 🛠️ Built With

- **HTML5** — page structure and content
- **CSS3** — styling, responsive layout, transitions, and animations
- **JavaScript** — hamburger navigation interaction
- **Google Fonts** — typography
- **GitHub Pages** — hosting and deployment

## 🚀 Run Locally

1. Clone or download this repository:

   ```bash
   git clone https://github.com/explorecodewithravi/the-sweets-corner.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use a local preview extension such as Live Server.

This is a static website and does not require a build step or package installation.

## 📦 Deployment

This project is hosted with GitHub Pages. To publish updates, push or commit changes to the repository's configured publishing branch and allow GitHub Pages to redeploy the site.

## 🔧 Customization

- Update the text, sweets, and images in `index.html`.
- Adjust colors, typography, spacing, and responsive breakpoints in `style.css`.
- Modify the mobile navigation behavior in `script.js`.
- Before using the site for a real business, replace the placeholder contact email in `index.html` with the correct business email.
